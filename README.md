## 🔧 使用技術（Tech Stack）

本專案為「口罩地圖」前端互動式地圖應用，主要使用以下技術實作：

### 前端技術
- **HTML5 / CSS3**
  - 負責頁面結構與基本樣式
  - 搭配自訂 CSS 與版面配置

- **Bootstrap 5**
  - 使用 Grid System 建立 RWD 版面
  - 快速套用表單、清單與 UI 元件樣式

- **Font Awesome**
  - 提供圖示（如庫存狀態、提示圖示）

### JavaScript 與套件
- **JavaScript（ES6）**
  - 處理資料邏輯、事件監聽與 DOM 操作

- **jQuery**
  - 簡化 DOM 操作與事件綁定
  - 使用 Ajax 取得 JSON 資料

- **Leaflet.js**
  - 地圖核心套件
  - 顯示 OpenStreetMap 地圖
  - 建立 Marker 與 Popup 資訊視窗

### 資料來源
- **健保署口罩資料（JSON）**
  - 藥局位置、成人與兒童口罩庫存數量

- **台灣縣市行政區資料（JSON）**
  - 動態產生縣市與鄉鎮區下拉選單

### 功能特色
- 縣市 / 鄉鎮區動態篩選
- 地圖 Marker 與清單雙向互動
- 依口罩庫存量顯示不同狀態樣式
- 點擊清單可定位並開啟地圖資訊視窗
